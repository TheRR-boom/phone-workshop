# Ремонт Плюс — GDD (MVP)

## 1. Концепция

**«Ремонт Плюс»** — 2D-симулятор мастерской по ремонту и продаже телефонов.
Игрок принимает клиентов, ставит диагноз, торгуется, разбирает устройства,
меняет модули и постепенно превращает маленькую мастерскую в прибыльный сервис.

- **Платформа:** Android / iOS, портретная ориентация.
- **Движок:** Godot 4.x, GDScript (2D, без 3D и физики).
- **Жанр:** tycoon + короткие головоломки на точность.
- **Аудитория:** 16+, играющие «по 5–10 минут»; знакомые с телефонами, но без
  требований к реальным техническим знаниям.
- **Сессия:** 3–7 минут: 1–2 заказа или один день.
- **Тон:** реалистичный сеттинг с бытовым юмором («Опять уронил в суп»),
  без фэнтези и абсурда.
- **Монетизация MVP:** отсутствует. Игра полностью офлайн, без рекламы и
  доната; в будущем — только косметика мастерской.

**УТП:** честная экономика ремонта. Игрок выбирает не «правильную кнопку»,
а компромисс: оригинальная деталь (дорого, надёжно, долгая гарантия) против
копии/б/у (дешевле, выше риск возврата и жалобы).

## 2. Кор-луп (один заказ)

1. **Клиент** приходит с жалобой и телефоном.
2. **Диагноз** — игрок выбирает неисправность из 5 по описанию симптома.
   Ошибка стоит репутации, две ошибки — клиент уходит.
3. **Запчасть** — выбор качества (оригинал / копия / б/у) из склада.
4. **Цена** — ползунок: себестоимость + работа + наценка. Клиент реагирует
   и либо соглашается, либо уходит.
5. **Ремонт** — мини-игры: разборка (винты по порядку) → этап по типу поломки
   (замена модуля drag-and-drop / чистка окислов тапами / пайка контактов
   удержанием) → проверка. Шанс успеха зависит от качества детали, модели
   и повреждений, нанесённых при разборке.
6. **Оплата, репутация, отзыв.** Возможен «возврат» от мошенника.
7. **День** закрывается: аренда, новые клиенты, новые лоты на витрине.

**Мета-луп:** деньги → запчасти и инструменты → сложные устройства и
дорогие заказы → витрина и продажа восстановленных телефонов → репутация
и поток клиентов.

## 3. Ключевые системы MVP

| Система | Реализация в MVP |
|---|---|
| Устройства | 3 класса: кнопочный (K1), старый смартфон (S3), современный (X20) |
| Неисправности | экран, батарея, разъём зарядки, залитие, динамик |
| Мини-игры | разборка (винты по порядку), замена модуля (drag-and-drop), чистка (тапы по окислам), пайка (удержание контактов), проверка |
| Запчасти | 4 типа × 3 качества × 3 класса; качество влияет на цену, шанс успеха и гарантию |
| Клиенты | обычный, срочный, скандальный, постоянник, мошенник |
| Ценообразование | рынок × характер клиента × репутация; торг и отказ |
| Репутация | 0–100, влияет на потолок цены и поток клиентов |
| Магазин | запчасти по классам + 4 улучшения (фен, ультразвук, реклама, подсветка) |
| Витрина | 3 слота: купил битый → восстановил → выставил цену → продал |
| Сохранение | JSON в `user://`, автосохранение, пауза при сворачивании |

## 4. Экраны и переходы

```
                 ┌──────────────┐
                 │  Мастерская  │  хаб: очередь клиентов, деньги, день
                 └──────┬───────┘
        ┌───────────────┼────────────────┬───────────────┐
        ▼               ▼                ▼               ▼
   ┌─────────┐    ┌───────────┐    ┌──────────┐   ┌───────────┐
   │  Заказ  │    │  Витрина  │    │  Магазин │   │   Склад   │
   └────┬────┘    └─────┬─────┘    └──────────┘   └───────────┘
        │               │
        ▼               ▼
   ┌─────────┐    ┌───────────┐
   │ Ремонт  │    │  Продажа  │
   └────┬────┘    └───────────┘
        │
        ▼
   итог заказа → Мастерская
```

- **Мастерская** — единственный «корневой» экран; нижняя навигация ведёт в
  Витрину / Магазин / Склад.
- **Заказ** — модальный поток: назад = отказать (с потерей репутации).
- **Ремонт** — линейный: винты → модуль → проверка → итог → Мастерская.
- Переходы — через `Router.go(key)` с затемнением 0.16 с.

## 5. Данные

### PhoneModel
`id`, `title`, `tier` (0/1/2), `base_value` (рыночная цена б/у),
`repairability` (0.78–1.0), `screws` (2/4/6), `color`.

### Fault
`id`, `title`, `symptom`, `part_type` (`screen|battery|port|speaker|""`),
`labor`, `difficulty` (1.0–1.4), `needs_cleaning`, `badge`, `color`.

### PartQuality
`id`, `title`, `cost_mul`, `reliability`, `warranty_days`, `color`.
Оригинал: ×1.0 / 99 % / 365 дн.; копия: ×0.55 / 92 % / 90 дн.;
б/у: ×0.30 / 78 % / 14 дн.

### ClientType
`id`, `title`, `pay_bonus` (−0.10…+0.15), `patience`, `scam_chance`,
`rep_mul`, `color`.

### Order (runtime)
`id`, `day`, `client_name`, `client_type`, `phone`, `fault`, `quality`,
`price`, `status`.

### Ключ склада
`"{part_type}:{quality}:{tier}"` → количество, например `screen:copy:1`.
Класс устройства в ключе обязателен: экран от кнопочного не подходит флагману.

### Сохранение (JSON, `user://repair_plus_save.json`)
```json
{
  "v": 1, "money": 3000, "rep": 50, "day": 1, "xp": 0,
  "inventory": {"screen:copy:1": 1},
  "upgrades": {"heatgun": true},
  "showcase": [{"phone_id": "s3", "fault_id": "screen", "ready": false}],
  "clients": [{"id": 1, "client": "regular", "phone": "s3", "fault": "screen"}],
  "stats": {"orders": 0, "failed": 0, "earned": 0}
}
```

## 6. Экономический баланс MVP

Старт: **3 000 ₽**, репутация **50/100**, 1-й уровень, 3 клиента в день,
склад: 1 экран + 2 батареи (копии) для кнопочных, по одной детали для S3.

**Аренда:** 300 ₽/день. **Штраф за провал:** запчасть списывается,
оплаты нет, −5 репутации.

| Устройство | Работа | Себестоимость (копия) | Рынок | Потолок при реп. 50 | Прибыль |
|---|---|---:|---:|---:|---:|
| K1, экран | 600 | 1 095 | 1 500 | 1 600 | ~505 |
| K1, батарея | 400 | 785 | 1 100 | 1 173 | ~388 |
| S3, экран | 600 | 2 762 | 4 472 | 4 770 | ~2 008 |
| S3, батарея | 400 | 1 493 | 2 348 | 2 505 | ~1 012 |
| X20, экран | 600 | 7 344 | 12 744 | 13 594 | ~6 250 |
| X20, батарея | 400 | 2 806 | 4 696 | 5 009 | ~2 203 |

Формулы:
- рынок = работа × (1 + 0.12 × tier) × сложность + цена оригинала;
- себестоимость = работа + цена выбранной детали;
- потолок клиента = рынок × (1 + характер) × (0.9 + репутация/300);
- рекомендованная цена = рынок × (0.95 + репутация/1000), но не выше 95 % потолка;
- прибыль = цена − себестоимость.

Стартовая цена специально проходит любого обычного клиента: игрок не должен
видеть заблокированную кнопку «Начать ремонт» до первого действия.

**Улучшения:** фен 1 500 (＋6 % к успеху на экран/батарею), ультразвук 2 500
(＋12 % к залитию), реклама 1 200 (＋1 клиент), подсветка витрины 2 000
(＋15 % к продаже). Полный апгрейд — около 7 200 ₽, то есть 2–4 игровых дня.

**Проверка баланса:** 3 заказа в день дают 1 500–4 000 ₽ прибыли на старте.
Аренда 300 ₽ не давит, но дисциплинирует. Цены на детали растут быстрее
работы — современные телефоны выгодны только при репутации 60+ и доступе
к складу, что и создаёт прогрессию.

## 7. Арт и звук

- 2D, плоские фигуры, крупные скругления, без текстур и партиклов.
- Палитра: фон `#0b0f14`, панели `#151c25`, акцент `#38e8a0`,
  опасность `#ff5a5f`, деньги/внимание `#ffb020`.
- «Иконки» — цветные буквенные бейджи (Э/Б/З/В/Д) и крупный текст:
  читается на 5" без прищуривания, не требует художника.
- Шрифт Noto Sans (OFL), Regular/Bold, кириллица и ₽.
- Звук в MVP отсутствует; в плане — короткие синтезированные щелчки
  (WebAudio-подход из веб-прототипа не переносится, нужен AudioStreamGenerator
  или 3–4 коротких .ogg).

## 8. Что НЕ входит в MVP

3D, мультиплеер, физика, сюжетные катсцены, прошивка (5-я мини-игра),
trade-in с торгом, сезонные события, облачные сохранения, реклама и донат.
