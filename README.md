# ИЗНУТРИ

Симулятор ремонта телефонов, где поломку нужно **найти руками**:
разобрать аппарат по слоям, осмотреть плату, прозвонить мультиметром
и только потом поставить диагноз. Godot 4, GDScript, 2D, портрет, тач.

## Чем отличается

Нет меню «выбери неисправность». Клиент называет симптом («не заряжается»,
«выключается на холоде»), а причин может быть несколько. Игрок разбирает
телефон в реальном порядке, находит улику на конкретном узле и подтверждает
диагноз. Ошибка в порядке разборки или инструменте ломает детали и снижает
шанс успешного ремонта.

## Что работает

- Разборка по слоям: винты Pentalobe → крышка (присоска + свайп) →
  Torx-винты → экранирующая пластина → разъём батареи → шлейфы → плата.
- Винты: неверная бита срывает шлиц и наносит урон.
- Пинч-зум, панорамирование, осмотр узла под «лупой» с поиском аномалии.
- Мультиметр: режимы V / R / C, пять реальных точек замера, реакция на дефект.
- Скрытые дефекты: вздутие батареи, окисление разъёма, залитие платы,
  обрыв шлейфа дисплея, окисление динамика.
- Смета после диагноза: качество детали, себестоимость, торг, отказ клиента.
- Экономика, репутация, аренда, магазин, склад, витрина, автосохранение.
- 3 устройства, отличающиеся числом винтов и платой.

## Запуск

```bash
godot --path .            # игра
godot --path . --editor   # редактор
```

Тесты (140 headless-проверок: разборка, дефекты, мультиметр, экономика,
вёрстка на трёх соотношениях сторон):

```bash
godot --headless --path . res://tests/smoke.tscn
```

## APK

Собирается в GitHub Actions (`.github/workflows/android.yml`) на каждый push:
Godot 4.7.2 + шаблоны экспорта, Android SDK, тесты, `--export-debug`,
подпись отладочным ключом. Файл — в артефактах и релизе `apk-build-N`.

Локально:

```bash
keytool -keyalg RSA -genkeypair -alias androiddebugkey -keypass android \
  -keystore debug.keystore -storepass android \
  -dname "CN=Android Debug,O=Android,C=US" -validity 9999 -deststoretype pkcs12
godot --headless --path . --import
godot --headless --path . --export-debug "Android" build/iznutri.apk
```

## Управление

- Тап по винту с выбранной битой — выкрутить.
- Присоска + свайп вверх по крышке — снять крышку.
- Лопатка: тап по разъёму — отключить, тап по модулю — снять.
- Тап без инструмента — осмотр узла (лупа).
- Мультиметр: выберите режим, тапните по контактной площадке.
- Два пальца — пинч-зум; один палец — панорамирование.
